GitHub Pages quick upload:
1. Create a new GitHub repository.
2. Upload the three HTML files from this folder to the repository root.
3. In repository Settings > Pages, choose Deploy from a branch.
4. Select the main branch and /(root), then Save.
5. GitHub will provide the HTTPS Pages address once published.
